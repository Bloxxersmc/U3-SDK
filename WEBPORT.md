# Unturned in the browser (WebGL / WebGPU)

Unofficial community port on the `web-port` branch. Not made or endorsed by Smartly Dressed Games.
Same license as the rest of the SDK: non-commercial, free to play. See LICENSE.txt and the
[U3 SDK FAQ](https://docs.smartlydressedgames.com/en/stable/u3-sdk/faq.html).

**Status:** offline singleplayer. The code compiles for WebGL, but it hasn't been built
or run in a browser yet: that needs the Unity editor (see "Build").

## How it works

| Desktop | Browser build |
|---|---|
| Steam client (`steam_api64.dll`) | `Assets/Plugins/WebGL/SteamOfflineStubs.c`: all 879 Steam API functions as no-ops, signed in offline as a local player. Generated by `Tools/WebPort/gen_steam_stubs.py`. |
| Worker threads (asset search, foliage streaming) | Run on the main thread (`WebThreadPool`, `FoliageStorageV2.MainThreadWorkerStep`). |
| Game folder next to the .exe | Browser virtual file system at `/unturned`, filled from a folder you pick (`UnturnedWebFS.jslib`, `WebFileSystem.cs`). Saves (`Worlds`, `Cloud`) persist in IndexedDB. |
| Windows asset bundles | Retargeted to WebGL and recompressed as chunked LZ4 by `Tools/WebPort/bundles/convert_for_web.py`, then streamed with `AssetBundle.LoadFromFile`. |
| Direct3D shaders inside bundles | `WebShaderFixer` re-points bundle materials at the same-named shaders compiled into the build (all SDK shaders are Always Included). |

## 1. Prepare game data (once, from your own install)

The game's content is not in the SDK and may not be redistributed, so each player converts their own copy:

```
python -m pip install --user lz4
python Tools/WebPort/bundles/convert_for_web.py --src "C:/Program Files (x86)/Steam/steamapps/common/Unturned" --out "%USERPROFILE%/Downloads/UnturnedWebData" --maps PEI
```

Core bundle + PEI is about 300 MB. `--maps all` adds every map (around 1.7 GB, likely too big for a browser tab).
Never commit or publicly host `UnturnedWebData`.

## 2. Build

- **WebGL:** Unity **2022.3.62f3** with **WebGL Build Support**. It has to be this exact version, because the
  core bundle was built with it. Open the project, then **Unturned > Web > Build WebGL**, or headless:
  `Unity.exe -batchmode -quit -projectPath . -buildTarget WebGL -executeMethod SDG.Unturned.WebPort.WebBuild.BuildWebGLCommandLine`
- **WebGPU:** needs Unity 6 (6000.0+). **Unturned > Web > Build WebGPU (Unity 6+)** refuses to run on 2022.3.
  Upgrading the project to Unity 6 is a separate step that hasn't been tried yet.

Output: `Builds/Web/WebGL` (or `WebGPU`).

## 3. Run

```
python Tools/WebPort/serve.py          # http://localhost:8080
```

Open it in Chrome or Edge, pick your `UnturnedWebData` folder, enter a name, and press Play.

## Check the code without Unity

`python Tools/WebPort/CompileCheck/compile_check.py` compiles the runtime code with the WebGL player defines,
using the Unity DLLs from an Unturned install (`--desktop` checks the normal build). Both currently compile with 0 errors.

## Known gaps / next steps

- Not built or run yet. Expect a round of engine-side fixes after the first build (shader variants, memory, startup order).
- Multiplayer: not supported. It would need a WebSocket/WebRTC transport and a server that accepts it.
- Pathfinding (A*), BattlEye and other third-party pieces that the SDK leaves out stay disabled, as in SDK builds.
- Memory: the WebGL heap tops out at 4 GB. Large maps will probably need lower texture quality.
