# Unturned in the browser (WebGL / WebGPU)

Unofficial community port on the `web-port` branch. Not made or endorsed by Smartly Dressed Games.
Same license as the rest of the SDK: non-commercial, free to play. See LICENSE.txt and the
[U3 SDK FAQ](https://docs.smartlydressedgames.com/en/stable/u3-sdk/faq.html).

**Status (Unity 6000.6.9f1, WebGL 2):** builds, boots, reaches the main menu, and loads PEI in offline singleplayer.
What still needs fixing is listed under "Known gaps". WebGPU hasn't been built yet.

## How it works

| Desktop | Browser build |
|---|---|
| Steam client (`steam_api64.dll`) | `Assets/Plugins/WebGL/SteamOfflineStubs.c`: all 956 Steam API imports as no-ops, signed in offline as a local player. Generated by `Tools/WebPort/gen_steam_stubs.py`. |
| Worker threads (asset search, foliage streaming) | Run on the main thread (`WebThreadPool`, `FoliageStorageV2.MainThreadWorkerStep`). |
| Game folder next to the .exe | Browser virtual file system at `/unturned`, filled from a folder you pick (`UnturnedWebFS.jslib`, `WebFileSystem.cs`). Saves (`Worlds`, `Cloud`) are kept in IndexedDB: loaded before the engine starts, written back every 15 s and when the tab closes. |
| Windows asset bundles | Retargeted to WebGL and recompressed as 128 KiB LZ4 chunks by `Tools/WebPort/bundles/convert_for_web.py`. |
| Direct3D shaders inside bundles | `WebShaderFixer` re-points bundle materials at the same-named shaders compiled into the build (all SDK shaders are Always Included). |
| Online services (live config, news, host bans, update check) | Skipped: those servers don't allow cross-origin requests from a web page. |
| Json.NET dynamic code | Turned off at startup (IL2CPP can't run Reflection.Emit). |

## 1. Prepare game data (once, from your own install)

The game's content is not in the SDK and may not be redistributed, so each player converts their own copy:

```
python -m pip install --user lz4
python Tools/WebPort/bundles/convert_for_web.py --src "C:/Program Files (x86)/Steam/steamapps/common/Unturned" --out "%USERPROFILE%/Downloads/UnturnedWebData" --maps PEI
```

Core bundle + PEI is about 300 MB. `--maps all` adds every map (around 1.7 GB, likely too big for a browser tab).
Add `--force` to reconvert after updating the tool. Never commit or publicly host `UnturnedWebData`.

## 2. Build

Unity **6000.6.9f1** with **Web Build Support** (Unity 6 is needed for WebGPU).

- First open only: **Unturned > Web > Import TMP Essential Resources** (or headless, without `-quit`:
  `Unity.exe -batchmode -projectPath . -executeMethod SDG.Unturned.WebPort.WebBuild.ImportTMPEssentialsCommandLine`).
- **WebGL:** **Unturned > Web > Build WebGL**, or headless:
  `Unity.exe -batchmode -nographics -quit -projectPath . -buildTarget WebGL -executeMethod SDG.Unturned.WebPort.WebBuild.BuildWebGLCommandLine -logFile Logs/webgl.log`
  (about 15 minutes; look for `[WebBuild] WebGL: Succeeded`).
- **WebGPU:** **Unturned > Web > Build WebGPU (Unity 6+)** / `...WebBuild.BuildWebGPUCommandLine`.

Output: `Builds/Web/WebGL` (or `WebGPU`).

To check that a converted bundle loads, without a browser:
`Unity.exe -batchmode -projectPath . -executeMethod SDG.Unturned.WebPort.WebBundleTest.Run -bundle "<path to bundle>"`.

## 3. Run

```
python Tools/WebPort/serve.py WebGL 8765
```

Open http://localhost:8765/ in Chrome or Edge, pick your `UnturnedWebData` folder, enter a name, and press Play.
(Port 8080 is reserved on some Windows PCs, so the examples use 8765.)

Shortcuts while testing:

- `python Tools/WebPort/serve.py WebGL 8765 --data "%USERPROFILE%/Downloads/UnturnedWebData"` also serves your data
  folder at `/gamedata/`, on localhost only. Then `http://localhost:8765/?localdata` loads it without the folder picker.
- `&autoplay` presses Play for you, and `&autoload=PEI` starts singleplayer on that map once the menu is up.
- Keep the tab visible: browsers throttle background tabs hard, and the game then runs at a frame every few seconds.

## Known gaps / next steps

- **Some textures load without pixel data** ("The image data of Texture ... has an unexpected size (expected N,
  got 0)"). Character skins and UI icons are affected, so the menu character renders grey.
  The same bundle loads fine in the Unity 6 editor, so the problem is specific to the WebGL player.
- **No sound:** the Windows bundles store audio as FMOD (Vorbis), which browsers can't decode.
  The converter would have to re-encode clips (e.g. to AAC).
- Multiplayer: not supported. It would need a WebSocket/WebRTC transport and a server that accepts it.
- Pathfinding (A*), BattlEye and other third-party pieces that the SDK leaves out stay disabled, as in SDK builds.
- Exceptions are built with full stack traces while startup is being debugged; switch `WebBuild.cs` back to
  `ExplicitlyThrownExceptionsOnly` for a smaller, faster build.
